ระบบจัดการ

✅ บันทึกสำเร็จ!
📌 วิธีใช้งาน:
1. แก้ไขข้อมูลในหน้านี้
2. กดปุ่ม "บันทึก" (ข้อมูลจะบันทึกในเบราว์เซอร์)
3. กดปุ่ม "Export JSON" เพื่อดาวน์โหลดไฟล์ data.json
4. อัพโหลดไฟล์ data.json ใหม่ขึ้น GitHub หรือ Cloudflare
วิธีอัปโหลดรูปภาพและวิดีโอ:
1. รูปภาพ: เลือกรูปจากคอมพิวเตอร์ → คัดลอกลิงก์ → ไปใช้ที่แท็บ "รูปภาพ"
2. วิดีโอ: อัปโหลดขึ้น YouTube → คัดลอก URL → ไปใช้ที่แท็บ "วิดีโอ"

คลิกเพื่อเลือกรูปภาพ หรือลากรูปมาวางที่นี่

อัปโหลดสำเร็จ!

สำหรับวิดีโอ ให้อัปโหลดขึ้น YouTube ก่อน แล้วคัดลอก URL มาวางในแท็บ "วิดีโอ"

อัปโหลดวิดีโอขึ้น YouTube
  • รูปภาพ: รองรับไฟล์ JPG, PNG, WebP (ขนาดไม่เกิน 5MB)
  • วิดีโอ: ให้อัปโหลดขึ้น YouTube แล้วใช้ลิงก์ Embed
  • ขนาดรูปภาพแนะนำ: 1200x800 พิกเซล สำหรับรูปหลัก
  • ขนาดรูปภาพแกลเลอรี่: 800x800 พิกเซล (สี่เหลี่ยมจัตุรัส)
